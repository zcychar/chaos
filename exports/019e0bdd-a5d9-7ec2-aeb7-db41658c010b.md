### 84. assistant (final_answer)

`retain` keeps only elements where the callback returns `true`.

For a vector like:

```rust
vec.retain(|item| condition(item));
```

Rust walks through the vector and removes every item where `condition(item)` is `false`.

So this code:

```rust
d.bus.cbs.retain(|f| !f(d.bus.ev));
```

means:

1. Iterate over every callback `f` in `d.bus.cbs`.
2. Call the callback with the current event mask `d.bus.ev`.
3. If `f(d.bus.ev)` returns `true`, remove that callback.
